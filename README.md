# Plug TV — Phase 1 scaffold

This branch contains the Phase 1 scaffold for the Plug TV project (Next.js + TypeScript + Tailwind + Supabase client + initial UI components).

Phase 1 included:
- Next.js app router setup
- TypeScript (strict)
- Tailwind CSS
- next-themes integration ready
- Framer Motion & Lucide React listed in package.json
- Supabase client setup (lib/supabaseClient.ts)
- Home page, Navbar, Footer, Hero, ChannelCard, ChannelGrid components
- Sample channel data (data/sampleChannels.ts)

How to run locally (Phase 1):
1. Install dependencies: npm install
2. Create .env.local with NEXT_PUBLIC_SUPABASE_URL and NEXT_PUBLIC_SUPABASE_ANON_KEY (optional for Phase 1 UI)
3. Run dev: npm run dev

This is Phase 1 only. Stop here and wait for approval before Phase 2.
